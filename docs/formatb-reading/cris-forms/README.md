# CRIS blank form templates (recovered from the Wayback Machine)

Blank data-collection form PDFs from the USDA **Current Research Information
System (CRIS)**, as served by the earliest CRISFRMS host, `ctr.uvm.edu/cris`
(University of Vermont, under a CSREES contract). Recovered 2026-09-16 because
the CRIS web-forms application ("CRISFRMS") was delivered over the web and its
own installer/binary was not located; these blank templates are the closest
surviving artifact of what the system captured.

CRIS collected data on four forms — AD-416 (Research Resume), AD-417
(Classification of Research), AD-418/419 (Funds & Staff Support), and AD-421
(Progress Report). All four are present below, in more than one vintage.

## Provenance

Each file is the raw archived object, pulled with the Wayback `id_` (original
bytes) modifier from `http://web.archive.org/web/<timestamp>id_/<original-url>`.
Verified as valid PDFs on download (`file`), but **not** page-by-page confirmed
to render as the expected blank form — open before relying on any one.

The AD-417 template exists here in two vintages with **different
classification schemes** — the older `ad417.pdf` classifies by Research
Problem Area / Activity / Commodity; `ad417r99.pdf` (1999) by Research Problem
Area / Subject of Investigation / Field of Science. Scope any AD-417 field
rules to vintage.

## CRISFRMS version evidence

`ad421.pdf` carries the printer footer **`CRISFRMS 6.xx/R&R 6 (2/95) printing
Form AD421`** — primary-source evidence that CRISFRMS existed as version 6.xx
dated February 1995, i.e. as software generating these forms *before* the
~2001+ web-forms system. Supports (does not yet prove) the hypothesis that a
standalone/offline CRISFRMS client predated the web incarnation.

## Statement of absence (recorded per project rule)

The **CRISFRMS software binary/installer** and the **2005 edition of the
"Manual for Preparing CRIS Forms"** (`cwf.uvm.edu/cris/crismanual_2005r1205.pdf`,
which uniquely carried the AD-419 chapter) were **not found** by web search plus
Wayback CDX lookups on 2026-09-16, searching the exact filenames/titles and the
relevant UVM/USDA hosts. This is provisional — it stands only until a wider
reading (e.g. reginfo.gov OMB ICR supporting-statement attachments, land-grant
research-office mirrors, or nifa/reeis Wayback hosts where the file may have
migrated) revisits it. A ~1997 HTML edition of the same manual survives at
`web.archive.org/web/19970626010253/http://ctr.uvm.edu/cris/crisman/m_manual.htm`
but omits AD-419.
